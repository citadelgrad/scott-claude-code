# Public reports

Only sanitized aggregate reports may be committed here. Never commit task text, expected state, raw trajectories, provider output, reasoning, secrets, canaries, private paths, or per-run hidden/sealed records.

`not-evaluated-v1.json` and `.md` are deterministic zero-run artifacts proving the report shape and fail-closed gate state. They are not model-evaluation evidence. Live release reports require separate authorization, all three frozen treatments, every model/harness stratum, validated pairs, and external-custodian redaction review.
